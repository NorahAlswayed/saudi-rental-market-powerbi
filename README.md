# تحليل سوق الإيجار السكني في السعودية
### Saudi Residential Rental Market Analysis | Power BI

![Dashboard](SA_Aqar.pdf)

## نبذة | Overview
لوحة تفاعلية في Power BI تحلل أكثر من 3,700 عقار للإيجار في السعودية، وتوضح مستويات الأسعار حسب المدينة والحي وعمر العقار.

An interactive Power BI dashboard analyzing 3,700+ rental properties across Saudi Arabia, covering price levels by city, neighborhood, and property age.

## الأسئلة التي يجيب عنها | Key Questions
- ما وسيط الإيجار وسعر المتر المربع؟
- ما أعلى 10 أحياء سعرًا؟
- كيف تختلف الأسعار بين المدن؟
- هل لعمر العقار تأثير على السعر؟
